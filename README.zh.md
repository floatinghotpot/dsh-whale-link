# WhaleLink（鲸语通）DSH 插件

**其他语言**：[English](README.md)

## 鲸语通是什么

鲸语通（WhaleLink）是**语音助手**——用语音和智能体沟通，无需打字，回复可以直接念出来。让智能体随身而行。

- **说话就是输入法。** 说一句话，文字直接写进输入框；可多段累积、编辑后再发送，不用切换模式。可选系统识别或离线本地识别，声音不出本机。
- **朗读回复。** 智能体的回复自动朗读，音色、语速随心调，边走边听、不必盯屏。
- **一处管理所有主机。** 接入的主机都在同一个列表里，不用记一堆地址和端口——主机再多也只有一个入口。
- **内网直连优先。** 同一网络下优先直连，延迟更低、更省流量；不在同一网络时自动走加密中转，不用来回改配置。
- **随时随地访问。** 主机主动建立出站隧道，穿透 NAT 与防火墙（只出不进），手机在任何网络下都能安全连回自己的机器。

## 这个插件是什么

`dsh-whale-link` 是鲸语通的 **DSH 桌面端插件**——负责「接入」这一半：把运行 DSH 的这台电脑接进鲸语通（DSH 的「设置」里会多出一个 **WhaleLink** 面板）。接入之后，这台电脑就出现在鲸语通的**主机列表**里，和你的其他主机一起集中管理；用手机或浏览器都能点进去。语音输入与朗读由鲸语通 App 提供，不在本插件内。

## 功能

- **在面板里完成，不用命令行。** 接入、断开、注销、状态，都在 **设置 → WhaleLink**。
- **两种接入方式。** 粘贴鲸语通网页版给出的一次性授权令牌，或用「鲸语通」App 扫码。
- **暂停不丢绑定。**「断开」只停隧道、保留令牌；「注销」清掉本地绑定并请求鲸语通吊销这台主机。
- **可选访问口令。** 只有你知道的一层锁：任何人（包括服务提供方）要进入这台主机都得先输对口令。随时开启/关闭。
- **诊断与修复。** 能看到是谁占着隧道、本机还装了哪些份插件，以及清掉残留锁。
- **远程也能选目录。** 插件把 DSH 的目录选择器固定为**浏览器内**形态——远端浏览器永远够不到宿主屏幕上的原生系统对话框。

## 环境要求

| | |
|---|---|
| DSH | **DSH Desktop**，或支持插件、命令行启动的 DSH（`dsh web`） |
| 服务器 | 鲸语通托管服务（面板已预填 `https://rdsh.cn`），或你自己部署的服务——见 [remote-dsh](https://github.com/floatinghotpot/remote-dsh) |
| `pnpm` | 仅当通过 DSH 的**插件**界面安装时需要 |

## 安装

两种形态，按你跑 DSH 的方式选一条。

### A. DSH Desktop（桌面版）

在 **DSH Desktop** 里：**插件** → **添加插件** → 输入 `dsh-whale-link`。

**⚠️ 安装后，请重启 DSH。** 安装或升级后，插件页可能显示「目录选择器已注册」之类的异常。原因是：

1. DSH 的目录选择器是一个单例服务（`directoryPicker`），只有两种实现：`native`（弹宿主 OS 对话框）和 `browse`（在页面里浏览）。
2. `native` 的对话框画在宿主屏幕上——远端用户在自己手机/浏览器里根本看不见、也点不到，选目录这个功能对远端等于没有。
3. `auto` 选择器默认会在桌面版选 `native`（有显示器、loopback、非 SSH），所以插件必须在启动时把它替换成 `browse`；而替换只能靠 patch 层，热应用来不及。

**完全退出并重新打开 DSH 后**，插件会把选择器重新固定为 `browse`，异常消失，远端即可选目录。

### B. 命令行 / 云服务器 / 嵌入式 Linux（推荐用 remote-dsh 启动 DSH）

如果 DSH 跑在云服务器、或树莓派这类嵌入式 Linux 上，**更推荐直接用 [`remote-dsh`](https://github.com/floatinghotpot/remote-dsh) 的 `rdsh` 来启动并托管 DSH**，而不是装这个插件：`rdsh` 会把 DSH 拉起来、并可以作为系统服务常驻，开机自启、崩溃自动重启。

```bash
npm install -g remote-dsh
rdsh join https://rdsh.cn        # 按提示粘贴鲸语通网页版给出的一次性授权令牌
rdsh serve                       # 前台运行：rdsh 自动拉起并托管 dsh web
rdsh service install             # 装成服务：systemd（Linux）/ launchd（macOS），开机自启、崩溃自动重启
```

- 想让**开机免登录**也自启：`sudo loginctl enable-linger $USER`（用户级服务默认只在登录期间运行）。
- 状态与日志：`rdsh service status`、`journalctl --user -u rdsh-join -f`。

如果你确实要在命令行形态下用这个插件（自己管理 DSH 进程），那就装到目标 profile 后自行启动：

```bash
dsh plugin --profile <name> add dsh-whale-link
dsh --profile <name>            # 启动该 profile（等价写法：dsh <name>）
```

> 同一条隧道只能有一个托管者：`rdsh` 正在跑时，插件面板会显示「已接入（由本机其它实例托管）」并保持只读。二选一，不要两边同时开。

## 使用

### 1. 接入本机

**推荐：用「鲸语通」App 扫码接入。**

1. 在 DSH 里打开 **设置 → WhaleLink**，点「**扫码接入**」；
2. 用「鲸语通」App 打开「地址列表」，在「远程智能体」一节点「**扫码添加**」，扫面板上的二维码；
3. 面板显示「已连接」即完成，这台主机已出现在你的主机列表里。

**也可以用令牌接入**（手上只有电脑时更方便）：

1. 在鲸语通网页版「添加主机」，复制页面给出的**服务器地址**与**授权令牌**（只显示一次）；
2. 打开 **设置 → WhaleLink**。服务器地址已预填，只有自建服务才需要改；
3. 粘贴**授权令牌**，可填**主机名称**，点「**接入**」。

接入成功后令牌会存在本机，以后再接入不必重新粘贴。

### 2. 从任何地方访问它

**推荐用「鲸语通」App**：登录后，在主机列表里点这台主机——手机就是你的入口，再多主机也都在同一个列表里。

在电脑上也可以**直接用浏览器**：打开鲸语通网页版，登录，在主机列表里点这台主机。App 和网页版看到的是同一份主机列表。

### 3. 平时不用管

绑定并连上之后，就**不需要再做任何操作**：每次 DSH 启动，插件会自动接入、自动重连；中途掉线也会自己恢复，面板状态始终是实时的。

只有需要暂停或解绑时，才去面板点一下：

| 操作 | 效果 |
|---|---|
| **断开** | 暂停这次连接，配置与授权保留；点「接入」或下次启动 DSH 会自动恢复。（内网直连口仍继续服务本网段。） |
| **注销** | 彻底解绑：删除本地绑定与令牌，并请求鲸语通吊销这台主机（尽力而为，失败会在面板提示）；面板回到「未接入」。 |

### 面板状态

| 状态 | 含义 |
|---|---|
| 未接入 | 从未接入，或已注销 |
| 连接中…／断线重连… | 正在建立隧道，或掉线后自动恢复 |
| 已连接 | 此刻可从外网访问 |
| 未接入（已断开，配置保留） | 曾接入过，当前暂停 |
| 已接入（由本机其它实例托管） | 本机的 `rdsh` CLI 或另一个 DSH 在用隧道，面板只读 |

## 数据存在哪

全部在 `~/.rdsh/` 下（host 配置路径可用 `RDSH_CONFIG` 覆盖）：

| 路径 | 内容 |
|---|---|
| `host.json` | 主机配置（`mode`、`hub`、`name`、访问口令、兼容开关） |
| `join-<host>[-<port>].token` | 持久化的 host 令牌（`0600`） |
| `e2ee-key.json` | 主机端端到端加密密钥对（`0600`） |
| `direct-secret` | 内网直连票据的 per-host 密钥（`0600`） |
| `join.lock` | 当前哪个进程在跑隧道（`0600`） |
| `device-id` | 稳定的设备标识（`0600`） |
| `rdsh-meta.json` | 上报的设备类型与组件版本 |

删掉这些文件等同于“从未接入”，但推荐用「注销」——它还会请求鲸语通吊销主机。

## 工作原理

- **服务端半**跑在 DSH 的**插件宿主进程**里（Cordis 函数插件）：DSH Desktop 就是桌面应用的主进程，命令行形态是 `dsh web` 的进程——插件和 DSH 的服务端本来就同一个进程，不需要另起进程。它通过 [`rdsh-gateway`](https://www.npmjs.com/package/rdsh-gateway) 向鲸语通服务建立**出站**隧道，并把流量转发给本机的 DSH Web 服务（`127.0.0.1:<webServer.port>`）。不在公网开任何入站端口。
- **内网直连**在接入期间额外监听一个本机端口（默认 `8442`），由 per-host 密钥签名的**一次性票据**把守；访问口令是可选的额外一层。
- **浏览器半**是手写的 `window.__ModuleLoader__` 模块，注册 **设置 → WhaleLink** 分区，并通过插件自己的 `/remote-access` RPC 路由与服务端半通信。
- **端到端加密**由隧道承载：中转只转发密文，读不到会话内容与文件。

## ⚠️ 从旧名字 `dsh-web-remote` 迁移

这个插件以前叫 **`dsh-web-remote`**，现在统一为 **`dsh-whale-link`**。两者是同一个插件、同一套实现，**不能装进同一个 DSH profile**：

- 两份 patch 都会禁用 `directory-picker` 并插入 `directory-picker-browse` 行，loader 会判定 `duplicate loader entry id`（`directoryPicker` 服务重复）——**DSH 无法启动**；
- 两者暴露同一个 `/remote-access` RPC 路由，并争抢同一把机器级 `~/.rdsh/join.lock`。

**已经装了旧包的，先卸旧的，再装新的：**

```bash
dsh plugin --profile <name> remove dsh-web-remote
dsh plugin --profile <name> add dsh-whale-link
```

DSH Desktop 里也可以直接在插件界面卸载旧的、安装新的。装完**重启 DSH**。

**不用重新接入。** 主机配置与授权令牌都在 `~/.rdsh/` 下，跟包名无关；换包后原来的主机仍会自动接入，面板状态和访问口令也都保留。

## 安全说明

- **只有你的账号进得来。** 接入不是“开门”：一台主机只对它所属的账号可达。
- **传输端到端加密。** 中转只看到连接元数据，看不到你的对话与文件。
- **本机还有你的一把锁。** 可选访问口令在本机校验，连服务运营方也绕不过去。
- **注销即清空。**「注销」删除本地绑定与令牌，并请求鲸语通吊销主机。
- 插件不开公网入站端口。隧道只在接入期间运行；内网直连口在主机保持 join 模式期间继续服务本网段（受票据把守，设了口令时还要过口令）。

## 相关项目

[**remote-dsh**](https://github.com/floatinghotpot/remote-dsh)（代码名 `rdsh`）是本套系统的开源项目，MIT 协议，在 GitHub 上公开：

- **连接平台**：`rdsh-hub`（账号、主机注册与路由，含内置中转）+ `rdsh-portal`（网页版）；
- **主机侧网关**：`rdsh` 命令行——在服务器 / 嵌入式设备上把 DSH 做成常驻服务用的就是它（见「安装」B）；
- **协议与对外 API**：隧道协议和对外 API 文档，供第三方接入；
- 本插件依赖的 `rdsh-gateway` 也由它发布。

想自己部署服务、或不想使用托管服务时，从那里开始。

## 开发

需要 **Node.js ≥ 22** 与 **pnpm ≥ 9**。

```bash
pnpm install
pnpm build     # tsc（strict）
pnpm test      # node --test
```

| 路径 | 内容 |
|---|---|
| `src/index.ts` | 服务端半：隧道生命周期、直连口、RPC 分发 |
| `src/rpc-route.ts` | `/remote-access` 前缀路由与其信封 |
| `src/lock-diagnostics.ts` | 锁持有者分类、本机安装扫描 |
| `client.js` | 浏览器半：设置分区 |
| `cordis.patch.yml` | Bundle patch：挂载插件行并固定目录选择器 |
| `locale/` | DSH 插件页面的 `meta.title` / `meta.description` / `meta.detail` |
| `docs/` | 插件详情页正文（中文 `DETAIL.zh.md` / 英文 `DETAIL.md`） |
| `icon.svg` | 插件图标 |

运行时依赖：`rdsh-gateway`——主机侧隧道实现，由 [remote-dsh](https://github.com/floatinghotpot/remote-dsh) 发布。具体版本以 [package.json](package.json) 为准（精确钉死，不用范围）。
